# Dear Ana Mosyne,
Contains the files for the game "Dear Ana Mosyne", created for the Hack Club event **"Haven"**. Play it here: https://chromalescence-labs.itch.io/dear-ana-mosyne

## Summary
### I. Lore
Lately, you have a hard time continuing to live your normal life. Every time you fall asleep, you wake up to a game where a person's face meets yours, but you can't quite figure out to whom it is.
It is so familiar yet it feels so far away. 

You shoot the neurons into the memory orbs until her photo slowly gets less blurry.

## How to Run
1. Go to this link: https://chromalescence-labs.itch.io/dear-ana-mosyne, no need to install anything on your device.
2. Click on the "Run Game" button found on the page.
3. (Hopefully) Enjoy playing the game!
4. Feel free to give us constructive criticism - we're beginners and are always open to respectful advice.
